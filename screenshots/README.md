## Upload steps

1. Open this folder in GitHub.
2. Select **Add file → Upload files**.
3. Select the five genuine screenshots.
4. Rename each file to the exact filename in the table.
5. Hide API keys, database URLs, passwords, personal email addresses, and customer information before uploading.
6. Select **Commit changes**.

The image files themselves must be uploaded; this guide only recreates the folder and documents the expected filenames.
